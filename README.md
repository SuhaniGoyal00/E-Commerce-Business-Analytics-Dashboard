# 📊 E-Commerce Sales & Business Analytics Dashboard

An interactive business analytics dashboard built using **Python, SQL, Pandas, Streamlit, and Plotly** to analyse e-commerce sales data and generate meaningful business insights.

## 📌 Project Overview

This project analyses e-commerce transactional data to monitor business performance, understand customer purchasing patterns, and identify sales trends. It transforms raw data into interactive visualizations to support data-driven decision-making.

## 🛠️ Technologies Used
- **Python:** Data analysis and processing
- **Pandas:** Data manipulation
- **SQL:** Business data analysis
- **Streamlit:** Interactive dashboard
- **Plotly:** Data visualization

## ✨ Key Features
- Tracks total revenue, profit, orders, and unique customers.
- Analyses monthly sales and revenue trends.
- Identifies top-performing products and categories.
- Compares regional sales performance.
- Analyses payment methods and order status.
- Provides interactive filters for date, category, region, and order status.
- Generates business insights and recommendations.

## 🔄 Project Workflow

1. **Data Collection:** Created a dataset containing 1,200 sample e-commerce orders.
2. **Data Processing:** Loaded and processed data using Pandas.
3. **Data Analysis:** Analysed revenue, profit, products, customers, and sales trends.
4. **SQL Analysis:** Used SQL queries to extract business insights.
5. **Data Visualization:** Created interactive charts using Plotly.
6. **Dashboard Development:** Integrated KPIs, charts, and filters using Streamlit.
7. **Insights:** Generated recommendations to identify business growth opportunities.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/E-Commerce-Business-Analytics-Dashboard.git
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Run the application**

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.
